# 🎯 Juego de Adivinanza en Python

Este proyecto es un sencillo juego de adivinanza implementado en Python. El programa genera un número aleatorio entre 1 y un nivel especificado por el usuario, y luego le pide al usuario que adivine el número. El juego proporciona retroalimentación hasta que el usuario acierta.

## 🚀 Cómo ejecutar

Asegúrate de tener Python instalado. Luego, abre una terminal y ejecuta:

```bash
python game.py
