# 🐦 twttr.py

Este programa elimina las vocales de un texto ingresado por el usuario, simulando el estilo abreviado que se usaba en los primeros días de Twitter (originalmente llamado "twttr").

## 📋 Descripción

Al ejecutar el programa, se solicita al usuario que ingrese una cadena de texto. Luego, se muestra esa misma cadena pero sin las vocales (A, E, I, O, U), tanto en mayúsculas como en minúsculas.

## 💻 Uso

Ejecuta el programa desde la terminal con:

```bash
python twttr.py
