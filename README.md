# 🐍 camel.py — Convertidor de camelCase a snake_case

Este programa en Python convierte nombres de variables escritos en formato **camelCase** al formato **snake_case**, siguiendo las convenciones de estilo recomendadas por Python.

## 📋 Descripción

En Python, se recomienda usar nombres de variables en minúsculas, separando las palabras con guiones bajos (`_`). Este programa solicita al usuario una variable en formato camelCase y muestra su equivalente en snake_case.

### 🔁 Ejemplos

```bash
$ python camel.py
camelCase: name
snake_case: name

$ python camel.py
camelCase: firstName
snake_case: first_name

$ python camel.py
camelCase: preferredFirstName
snake_case: preferred_first_name
