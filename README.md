# 🎶 Adieu.py
Este programa interactivo en Python despide a una lista de nombres al estilo de la canción So Long, Farewell de The Sound of Music. Utiliza la biblioteca inflect para generar frases gramaticalmente correctas con comas y "and" al final.

## 📋 Descripción
El usuario ingresa nombres uno por uno. Al finalizar la entrada (presionando Ctrl-D), el programa imprime una despedida con todos los nombres, formateados correctamente:
```bash
Adieu, adieu, to Liesl, Friedrich, Louisa, Kurt, Brigitta, Marta, and Gretl
```
Este ejercicio está inspirado en la línea de la canción:

>   Adieu, adieu, to yieu and yieu and yieu

## 🛠️ Requisitos

Biblioteca inflect

Instalación de inflect:

```bash
pip install inflect
```

## 🚀 Ejecución
Ejecuta el programa con:

```bash
python adieu.py
Ingresa los nombres uno por uno:

Name: Liesl
Name: Friedrich
Name: Louisa
```
Finaliza la entrada con Ctrl-D (Linux/macOS) o Ctrl-Z seguido de Enter (Windows).
