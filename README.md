# 🧮 Pequeño Profesor

Este proyecto simula el clásico juguete educativo "Pequeño Profesor", una calculadora que plantea problemas matemáticos simples para que los niños los resuelvan. El programa genera 10 problemas de suma y evalúa las respuestas del usuario, permitiendo hasta tres intentos por problema.

## 🚀 Cómo ejecutar

Asegúrate de tener Python instalado. Luego, ejecuta el programa desde la terminal:

```bash
python professor.py
