# 🧮 Interpreter.py

Este proyecto es un pequeño intérprete aritmético escrito en Python. Su propósito es solicitar al usuario una expresión matemática simple en formato `x y z` (por ejemplo, `3 + 4`) y devolver el resultado como un número de punto flotante con un decimal.


## 🚀 Cómo ejecutar

1. Ejecuta el programa con:

```bash
python interpreter.py
