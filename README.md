# 💰 Bitcoin Price Checker

Este proyecto es un script en Python que permite consultar el precio actual de Bitcoin y calcular el costo total de comprar una cantidad específica de Bitcoins en USD. Utiliza la API de CoinCap para obtener datos en tiempo real.

## 📦 Requisitos

- Python 3.x
- Módulo `requests` (instalable con `pip install requests`)
- Clave API de [CoinCap](https://coincap.io/)

## 🛠️ Instalación

1. Clona este repositorio o descarga el archivo `bitcoin.py`.
2. Instala las dependencias necesarias:
   ```bash
   pip install requests
